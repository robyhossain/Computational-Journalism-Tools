# 📊 Computational Journalism & OSINT Tools

Welcome to my central repository for custom-built automation tools, scripts, and extensions. 

As a researcher transitioning from linguistics to computational social science, I build these tools to solve real-world bottlenecks in digital investigations, media monitoring, and data journalism. This repository contains the tools I use daily for fact-checking and media narrative analysis.

---

## 📂 Project Directory

### 1️⃣ Chrome Extensions (`/Chrome-Extensions`)
Custom browser extensions designed to automate web scraping and enhance open-source intelligence workflows.

* **[OSINT-Media-Scraper](./Chrome-Extensions/OSINT-Media-Scraper)** 
  * *Description:* A powerful extension that automates Google Search scrolling, extracts hundreds of URLs, removes duplicates, and pushes clean structured data (Title, URL, Date, Platform) directly to Google Sheets.
  * *Tech Stack:* JavaScript (DOM Manipulation), Chrome Extension APIs (Manifest V3), HTML/CSS.

### 2️⃣ Google Apps Scripts (`/Google-Apps-Scripts`)
Backend scripts to format, clean, and manage large datasets inside Google Workspace.

* *(Adding soon)* - Scripts used to bridge the Chrome extensions with Google Sheets databases seamlessly.

## 🚀 Why I Build These Tools
Manual data collection is the biggest enemy of investigative journalism. Whether it's mapping the digital framing of a specific event or archiving thousands of news reports for NLP analysis, these tools help shift the focus from **data gathering** to **data analysis**. 

## 🛠️ Core Skills Demonstrated
* **Workflow Automation:** Bridging browser events with cloud databases.
* **Data Extraction & Cleaning:** DOM parsing, deduplication, and structured formatting (CSV/JSON).
* **Problem Solving:** Creating practical, low-latency solutions for everyday newsroom challenges.
